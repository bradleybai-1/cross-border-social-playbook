# 内容生产：首批清单 / 拍摄 SOP / 分镜模板

> 这一章是「方案能不能被真的执行」的分水岭。
> 写不出逐秒分镜的方案，客户拿到手就卡在"不知道怎么拍"。

---

## 一、首批内容明细（第四章 4.1）

**表格化，12–16 条**，列固定：

| # | 选题 | 平台 | 时长 | 类型 / 目的 | 核心信息（参数或结论） | 拍摄要点 | 优先级 |
|---|---|---|---|---|---|---|---|

**四条硬要求**：
- 优先级用 ⭐⭐⭐（爆款候选）/ ⭐⭐（常规）/ ⭐（补充）
- 每条「核心信息」**必须含至少一个数字或具体结论**（±0.1 mm / 80 MPa / 15 天开模 / NOT {竞品材料}）
- 「拍摄要点」要写到**机位、动作级别**（例：卡尺夹住断面读数的瞬间，微距，读数屏占画面 1/3）
- 「类型 / 目的」要明确这条是为「曝光」还是为「证据」，不能全写"产品展示"

## 二、逐秒分镜模板（配套脚本用）

单条视频的脚本按这个表写，列固定：

| 时间 | 画面 | 镜头 / 运镜 | 字幕（英文，烧字） | 口播（英文） | 音效 |
|---|---|---|---|---|---|

### 写法规则

1. **时间精确到 0.5 秒**（0.0–2.0s / 2.0–6.5s），不要写"开头""中间""结尾"
2. **前 2 秒必须是动作或数字**，禁止 Logo 开场、厂房航拍开场
3. **字幕全程烧字（burned-in）**，且必须含采购关键词 —— 多数人静音刷，字幕就是唯一的口播
4. **口播用短句**，一句一个信息，不写长难句（买家可能是非英语母语）
5. **字幕用大写强调结论**（`MEASURED EVERY BATCH` / `NOT {竞品材料}`）
6. **音效写具体的现场声**（卡尺"嗒"、火焰声、产线运转声）—— 现场声是专业感来源
7. **时长 15–30 秒为主**，Shorts 版可压到 30s，长视频版另写

### 结构模板（一个通用骨架）

| 时间 | 用途 | 要求 |
|---|---|---|
| 0.0–2.0s | 钩子 | 一个具体动作或一个具体数字，必须让人停住 |
| 2.0–8.0s | 建立场景 | 谁在做、做什么、为什么重要 |
| 8.0–18.0s | 给证据 | 参数 / 实测 / 对比，必须出现数字 |
| 18.0–25.0s | 给结论 | 一句话说清这说明什么 |
| 25.0–30.0s | 给动作 | 一个 CTA（评论区关键词 / 主页 / 私信） |

## 三、拍摄 SOP：一个拍摄日拍够一个月

给清单，必须含四项：**场地 / 顺序 / 每条覆盖哪几个脚本 / 时长**。

| 类型 | 需要拍摄日 |
|---|---|
| 纯产品类 | 1 个拍摄日（4 小时）够 12–16 条 |
| 需产线 + 实测类 | 2 个拍摄日（4h + 3h） |
| 需场景 / 模特类 | 2–3 个拍摄日 |

### 三条关键要求

1. **手机 4K 竖屏 + 横屏各拍一版** —— 这是一源多剪的前提。只拍竖屏，YouTube 长视频就没素材
2. **按场地分区拍摄**，不要按选题顺序 —— 换场地的时间成本远大于换选题
3. **同一动作多机位多景别各拍一条**（全景 + 中景 + 微距），剪辑时才有选择

### 拍摄日清单格式

| 时段 | 场地 | 覆盖脚本编号 | 需准备的实物 |
|---|---|---|---|
| 09:00–10:30 | 产线 | #{1,2,5} | 待加工件、防护 |
| 10:30–12:00 | 检测台 | #{3,4,8} | 卡尺、拉力机、样条 |
| 13:30–15:00 | 成品区 | #{6,7} | 包装、装柜 |

## 四、素材真实性红线（固定 3–5 条）

当前主流平台对 AI 生成与同质化内容有自动执法，以下五条不可越：

1. **不用图库图冒充实拍**
2. **不摆拍做不到的参数**（测不出来就别拍）
3. **不做夸张对比**（易被判误导，且懂行的买家一眼看穿）
4. **真人实拍 + 真实产线**是当前既安全又被平台鼓励的方向
5. **AI 生成的画面如使用，需按平台要求申报商业推广**（涉及合规，见 `06-output.md` 第七章）

## 五、「看不见的产品」内容公式

适用于产品埋在结构里、外观上拍不出差别的品类（隔热条、密封件、涂层、胶粘剂、内部零件等）。

把看不见的做成看得见的证据链，六个环节按顺序拍：

```
① 粒料/原材料配比  → ② 挤出/成型精度  → ③ 内部结构（玻纤分散/层数/壁厚）
→ ④ 性能实测（拉力/耐温/公差/爆破）  → ⑤ 装到成品上墙/上车  → ⑥ 认证报告
```

**对比实验类选题是抢行业话语权的捷径**：A 材料 vs B 材料（烧 / 掰 / 拉 / 泡 / 冻）。

争议性 = 传播性。这条在 B2B 里同样成立——同行会来看，会转发，会在评论里吵，而这些都推高分发。

## 六、图卡与帖子母版

### 规格图卡（Spec Card）母版

单参数一图，6 图一组。字段固定：

| 字段 | 说明 |
|---|---|
| 型号 | 大字号，左上 |
| 材质 / 牌号 | 一行 |
| 关键规格 | 1–2 个，带单位 |
| 公差 | 带符号（±0.1 mm） |
| 性能值 | 带单位与测试条件 |
| 认证 | 图标或缩写 |

**做 3 张基础模板就够**：`型号对比表` / `公差与性能表` / `应用场景图`。Canva 类工具即可，一次做好全部复用。

### Facebook 群组帖母版

```
[行业问题 / 常见误区]
（一句话，不要标题党）

[我们的做法与数据]
（2–3 行，必须含数字）

[欢迎交流 / 索取规格表]
（不带价格、不带链接）
```

不带价格、不带链接是硬要求——带了就是广告，会被踢，还会关联主页风险。

### 询盘钩子（每条视频固定置顶一条）

```
Comment "{关键词}" and we'll DM you the spec sheet + sample policy + price list.
```

发布后 **30 分钟内由账号自己置顶**。
