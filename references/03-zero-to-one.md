# 零到一账号搭建清单

> 触发条件：客户五平台账号全空，或只有空壳主页。
> 用法：替代标准诊断的第 1.2 节，并在附录展开为可打勾清单。
> 来源：多项目结构提炼（0→1 全新建号类项目沉淀）。

---

## 使用前提：0→1 的诊断逻辑不一样

| 有号待优化 | 零到一（无号/空号） |
|---|---|
| 有数据可分析 → 做**数据体检** | 无数据可分析 → 做**环境体检 + 门面体检** |
| 核心是内容策略与结构复用 | 核心是**能不能安全地把号建起来** |
| 目标 = 提升中位数播放 | 目标 = **装修 100% 完成 + 各平台 ≥ 8 条内容** |

诊断章相应改写：

- 1.2 改为「{N}平台账号现状体检（截图核验）」—— 逐平台标注「未注册 / 已注册空壳 / 有内容但未装修」
- 1.4 改为「零到一阶段最容易踩的 5 个坑（先避开，再谈内容）」

---

## 第 0 步：运营环境（做错这一步，后面全白做）

| 项 | 要求 | 说明 |
|---|---|---|
| 网络出口 | **固定、干净、稳定的出口 IP**，一个企业只用一个出口 | 频繁换 IP / 用公共免费代理 = 新号最高危行为 |
| 设备 | 建议**一账号一设备或一浏览器环境**（可用浏览器多环境隔离） | 同一设备登录十几个新号容易被关联 |
| 账号安全 | 全部开启**两步验证（2FA）**；绑定**企业邮箱**（非个人免费邮箱）；记录恢复码 | 新号被盗 → 申诉极难 |
| 管理工具 | **Meta Business Suite / Business Manager** 统一管理 Facebook + Instagram；YouTube 用**品牌账号**（Brand Account） | 避免个人号绑定，便于后续多人协作与授权 |
| 记录表 | 建一张《账号台账》：平台 / 邮箱 / 手机 / 2FA 备份 / 管理员 / 注册日期 | 交接与申诉的唯一依据 |

**为什么第 0 步在前**：账号异常的根源往往不是内容，是环境。环境不干净的号，后面发再好的内容也起不来。

---

## 第 1 步：注册与开号（顺序很重要）

1. **优先 Facebook + Instagram**（用 Meta Business Suite 一次打通），再开 **YouTube**（Google 品牌账号），最后 **TikTok、X**（俄语区客户加 **VK**）
2. 注册信息**必须真实一致**（公司全称、地址、电话、域名邮箱）——**虚假信息是封号主因**
3. **注册时不要开代理跳区**；注册国家/地区与目标市场无关，**与公司实际所在地一致最安全**
4. 注册后**先别发帖**，先完成资料填写（第 2 步）

---

## 第 2 步：主页装修（零到一阶段最高性价比的一步）

| 装修项 | 要求 | 示例 |
|---|---|---|
| **品牌名（统一）** | 各平台统一为「品牌 + 品类词」，便于搜索命中 | `{Brand} Thermal Break Strip` 这类结构（公司全称可用于 Facebook / YouTube 主标题） |
| **头像** | 统一用品牌 Logo（白底/透明底），或产品剖面特写 | 各平台一致 → 建立识别 |
| **背景/封面** | **产品剖面 + 应用场景 + 认证标识**三合一 | 不要用纯厂房航拍 |
| **Bio（统一模板）** | 结构：`Who we are ｜ What we make ｜ Certificates ｜ Sample & MOQ ｜ Contact` | 见附录 B |
| **CTA 按钮** | Facebook：`Send Message` / `WhatsApp`；YouTube：`About` 放官网；TikTok / Instagram：Bio 挂 Linktree | 让买家 3 秒内找到联系方式 |
| **置顶内容** | 每平台置顶 1 条最能说明身份的内容（建议产线全流程 或 规格表邀约） | 首月内完成 |
| **IG Highlights** | 建 4 个分类：`Products` / `Factory` / `Test Reports` / `Certificates` | 让新访客 30 秒看懂你 |
| **YouTube 频道** | 建 3–4 个播放列表（对应内容栏目）+ 频道关键词填采购搜索词 | 帮算法做主题聚类 |
| **语言** | **全部英文**（含账号名），移除中文标题 | 中文标题会损失海外搜索流量 |

---

## 第 3 步：养号期（注册后第 1–2 周，每天 15 分钟）

| 动作 | 频次 | 目的 |
|---|---|---|
| 完善资料（补头像、简介、联系方式、地址） | 一次性 | 平台判定「真实企业」的第一信号 |
| 浏览同行动态 + 关注 20–30 个行业账号 | 每天 10 分钟 | 让算法把你归类到正确兴趣池 |
| 正常互动（点赞/收藏/评论 3–5 条行业内容，**评论要有行业观点，不要只发 emoji**） | 每天 | 建立「真人」信号 |
| 加入 Facebook 行业 Groups（先看、先答，不推广） | 每天 1–2 个 | 2 周后再发产品帖 |
| **发布节奏** | **第 1 周 2 条、第 2 周 3 条、第 3 周起进入正常节奏** | 避免「新号突然高频」触发风控 |
| **不要做** | 群发私信、复制粘贴同一句评论、大量加陌生人好友、发带明显广告语的内容 | 这些是新号被封的高频原因 |

**养号期的核心产出不是内容，是「账号可信度」。** 前 2 周只互动不发广告。

---

## 第 4 步：内容资产准备（与养号并行）

| 资产 | 说明 | 交付形态 |
|---|---|---|
| **品牌素材包** | Logo（透明底/白底）、主色、字体、品牌角标 | 一次做好，全部内容复用 |
| **规格图卡模板** | 在产品参数表基础上做 3 张模板：`型号对比表` / `公差与性能表` / `应用场景图` | Canva / 设计工具 |
| **首批视频素材** | 按拍摄 SOP，**1–2 个拍摄日拍完首月 12 条** | 手机 4K 竖屏 + 横屏各一版 |
| **认证与报告** | 检测报告、标准符合性文件、企业资质（**需客户提供**） | 图卡 + 视频内展示 |
| **询盘三件套** | 规格表 PDF + 样品政策 + 报价单模板 | 用于私信秒回 |

## 0→1 阶段的平台权重（不要平均用力）

**零到一阶段最稀缺的是产能与素材，不是账号。**

| 客户类型 | 建议权重 |
|---|---|
| B2B 制造业（通用） | **YouTube + Facebook 占 70%**（B2B 搜索与询盘）；TikTok / Instagram 承担曝光与门面；X 每周 1 条背书 |
| 视觉类（家居/纺织/包装） | **Instagram + Facebook 占 70%**；TikTok 曝光 |
| 俄语区出口 | **VK + YouTube 占 70%** |

理由：账号多 ≠ 内容多。多平台会把首月 12–16 条的产能摊薄，每个平台都不够 8 条，反而过不了平台的"活跃度"门槛。

---

## 「看不见的产品」内容公式

适用于产品埋在结构里、外观上拍不出差别的品类（隔热条、密封件、涂层、胶粘剂、内部零件等）。
把看不见的做成看得见的证据链，六个环节按顺序拍：

```
① 粒料/原材料配比  → ② 挤出/成型精度  → ③ 内部结构（玻纤分散/层数/壁厚）
→ ④ 性能实测（拉力/耐温/公差/爆破）  → ⑤ 装到成品上墙/上车  → ⑥ 认证报告
```

**对比实验类选题是抢行业话语权的捷径**：A 材料 vs B 材料（烧 / 掰 / 拉 / 泡 / 冻），争议性 = 传播性。

---

## 0→1 首月务实目标

| 指标 | 首月目标 |
|---|---|
| 账号搭建 | 各平台装修 **100% 完成** + 各平台 **≥ 8 条内容** |
| 播放 | **不看绝对值**，看「中位数是否走出个位数」 |
| 粉丝 | 不设硬指标 |
| 询盘 | ≥ 3 条可追踪 |

> 零到一阶段，**「建起来」本身就是最大成果**。不要给客户不可能实现的播放承诺，会把执行团队逼到作假。
