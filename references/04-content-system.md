# 规划章写作法（第二章 2.1–2.7）

> 规划章的作用是回答「一个月内具体做什么」。
> 它必须能被排进日程表、能被逐项打勾，不能是"策略建议"。

---

## 2.1 平台矩阵分工

先给一张分工表：

| 平台 | 角色 | 首期权重 | 主要任务 |
|---|---|---|---|
| Facebook | 询盘成交位 | 30% | 主页四件套 + 群组渗透 + Messenger 承接 |
| TikTok | 曝光引擎 | 40% | 搜索优化 + 系列化 + 评论区钩子 |
| YouTube | 信任与搜索 | 30% | 采购搜索词命中 + 长视频证据链 |

然后一句话说清分工原则：**「同一批素材，{N} 种剪法，各司其职」——严禁一稿 {N} 发。**

### 权重不要平均

| 阶段 | 权重分配 |
|---|---|
| 0→1 阶段 | **70% 给 1–2 个主战场**，其余做门面 |
| B2B 制造业常见组合 | TikTok（曝光）+ Facebook（询盘） |
| 高选型决策品类 | YouTube（搜索信任）+ Facebook（询盘） |
| 视觉驱动品类 | Instagram + Facebook |

理由：账号多 ≠ 内容多。产能固定时，平台越多每个平台越不够量，反而过不了平台的活跃度门槛。

---

## 2.2 内容板块与占比

表格，5–6 个板块，**占比合计必须 = 100%**，每板块给形式与 3 个主题示例：

| 板块 | 占比 | 形式 | 主题示例 |
|---|---|---|---|
| 产线与工艺 | 25% | 竖屏短视频 15–30s | 成型 / 切割 / 装配全流程 |
| 性能实测 | 25% | 实测短视频 + 图卡 | 卡尺读数、拉力断点、耐温测试 |
| 选型科普 | 20% | 口播 / 图文 | A vs B 对比、怎么选规格 |
| 应用场景 | 15% | 实拍 | 客户现场、安装、成品 |
| 信任证据 | 10% | 图卡 / 长视频 | 认证、检测报告、装柜 |
| 行业观点 | 5% | 图文 / 短文 | 常见误区、行业标准变化 |

**B2B 制造业基准底线：证据型（实测 + 工艺）≥ 45%，纯产品展示不超过 20%。**

低于这条线，内容就变成产品图流水账，买家不会为它询盘。

---

## 2.3 首月 4 周内容日历

表格，列：`周次 | 日期 | {平台A} 条数 | {平台B} 条数 | 本周重点`

- **总量基准**：单平台 12–16 条；双平台合计 24–28 条；三平台以上不超过 12 条主线
- **第 1 周同时承载「装修整改」**，内容量可下调
- **每周必须有一个重点**：第 1 周门面、第 2 周系列化、第 3 周评论区、第 4 周复盘迭代

> 每周重点这一列最容易被写成"继续发内容"。没有明确重点，四周就变成四周一样的一堆内容。

## 2.4 发布时间建议（必须换算成北京时间）

**统一换算成北京时间 GMT+8，输出表格**：

| 平台 | 目标市场当地最佳时间 | 换算北京时间 | 依据 |
|---|---|---|---|

### 时区换算基准（常用市场）

| 市场 | 时区 | 与北京时差 | 当地 9:00 → 北京 | 当地 19:00 → 北京 |
|---|---|---|---|---|
| 英国 | GMT/BST | -8h / -7h | 17:00 / 16:00 | 次日 3:00 / 2:00 |
| 西欧（德法） | CET | -7h / -6h | 16:00 / 15:00 | 次日 2:00 / 1:00 |
| 美东 | EST/EDT | -13h / -12h | 22:00 / 21:00 | 次日 8:00 / 7:00 |
| 美西 | PST/PDT | -16h / -15h | 次日 1:00 / 0:00 | 次日 11:00 / 10:00 |
| 中东（沙特/阿联酋） | AST/GST | -5h | 14:00 | 次日 0:00 |
| 东南亚（越南/泰国） | ICT | -1h | 10:00 | 20:00 |
| 印尼 | WIB | -1h | 10:00 | 20:00 |
| 俄罗斯（莫斯科） | MSK | -5h | 14:00 | 次日 0:00 |
| 巴西 | BRT | -11h | 20:00 | 次日 6:00 |
| 尼日利亚 | WAT | -7h | 16:00 | 次日 2:00 |

**夏令时注意**：欧美有夏令时，时差会差 1 小时。跨夏令时切换期（3 月 / 10 月末前后）要在方案里标注一句。

### 各平台最佳时段（当地时区）

| 平台 | 最佳时段 |
|---|---|
| Facebook | 周二至周四 9:00–11:00 |
| Instagram | 周一 / 周四 / 周五 午休与晚间 |
| TikTok | 周二至周四，用户活跃时段（当地 19:00–22:00 为主） |
| YouTube | 周四 / 周五 / 周六 晚间（Shorts 不受此限，全天可发） |
| LinkedIn | 周二至周四 晨会前与午休 |
| X | 周一 / 周四 / 周五 |
| VK | 俄语区工作日晚间（当地 19:00–22:00） |

> **输出必须写成「北京时间 X:00（当地 Y:00）」**，让执行的人能直接排班。只写当地时间等于没写。

## 2.5 账号装修与整改清单

按平台分小节，每平台给**逐项可打勾**的清单。

### 整改顺序铁律：门面 → 链接一致性 → 内容

先修「页面报错 / 无法加载 / 认证不通过」这类硬问题，再谈内容。**门面打不开，内容做得再好都是白做。**

详细清单见 `03-zero-to-one.md` 附录 A（存量账号同样适用，标「存量优化」而非「重建」）。

### 存量账号：整改周内容量必须减半

零到一有「养号期」规则（前 2 周只互动不发广告），存量账号没有 —— 但存量账号更需要。

**规则：第 1 周定为整改周，内容量下调到正常量的 50%，门面改完再恢复节奏。**

为什么：门面没改好就按正常节奏发内容，等于把流量往漏桶里倒。简介不说明卖什么、外链点不通、handle 搜不到 —— 这时候每发一条，都是把一次曝光浪费掉。而内容量减少换来的是整改时间，这笔交换永远划算。

**第 1 周必须做完这三件事，缺一件都不进第 2 周：**

1. handle / 简介 / 免责声明全部改完（改完用另一台设备搜一遍，确认能搜到）
2. 外链点进去能正常浏览、能联系上 —— **自己用手机点一遍**，不要假设链接是好的
3. 关注并真实评论 20–30 个目标圈层账号

> 第 3 条最容易被跳过。存量账号粉丝不涨，八成就是只发不看 —— 一个不关注任何人的账号，在社群里等于不存在。

## 2.6 首月目标（务实区间）

**必须是区间 + 明确前提「不含任何广告投放」。** 按平台给 4–6 个指标：

| 指标 | 首月目标 | 说明 |
|---|---|---|
| 内容产出 | {N} 条 | 主线 {n} 条 + 机动 |
| 单条播放中位数 | 从 {X} 提升到 {Y} | 不看单条爆款，看中位数 |
| 粉丝 | 从 {X} 到 {Y} | 新号首月目标要低 |
| 可追踪询盘 | ≥ {N} 条 | 必须可追踪（DM / 表单 / WhatsApp） |
| 装修完成度 | 100% | 首月第一成果 |

### 变体：C 端 / 收藏型账号的首月目标

B2B 看询盘数，C 端要加两个更前置的指标 —— 因为 C 端的成交发生在账号之外（独立站、线下店），光看询盘会漏掉真实意向。

| 指标 | 首月目标 | 说明 |
|---|---|---|
| 内容产出 | {N} 条 | 同上 |
| 单条播放中位数 | 从 {X} 翻倍到 {Y} | 中位数才代表算法认不认你 |
| **收藏 / 保存数** | 从 {X} 到 {Y} | 购物意图的直接信号，权重高于点赞 |
| **主页外链点击** | ≥ {N} 次 | **比粉丝更能反映真实意向**，首月主 KPI 建议用它 |
| 粉丝 | 从 {X} 到 {Y} | 粉丝是最慢的指标，不要拿它当主 KPI |
| 可追踪询盘 | ≥ {N} 条 | DM / WhatsApp / 表单 |
| 装修完成度 | 100% | 首月第一成果 |

**禁止写「播放量破 10 万」这类不可控指标。** 目标定了不可控的数字，执行团队会被逼着作假，最后你连真实数据都拿不到。

---

## 2.7 复盘追踪机制

固定动作，不要写复杂：

- **每周一 30 分钟**，看 4 个指标：中位数播放 / 完播率 / 互动率 / 询盘数
  - **C 端账号换成**：中位数播放 / 完播率 / **收藏数** / **外链点击**。收藏 =「我以后要买」，外链点击 = 真的动身了；点赞在这里是最弱的信号
- 保留表现最好的 2 条结构，做续作
- 砍掉表现最低的 2 类选题
- 执行后由客户方对接人回填，方案里只给机制不给假数据
