# 输出契约：方案骨架与附录标准

> 这是**唯一规定整份方案长什么样**的文件。章节标题照抄，不要改名、不要增删章。
> 每次产出前读一遍骨架，产出后拿 `SKILL.md` 第 6 节自检。

## 一之二、第二份交付物：配套视频脚本方案

**上面这个骨架是主方案。它之外还有一份独立文档。**

| | 主方案 | 配套视频脚本方案 |
|---|---|---|
| 回答 | 做什么、为什么 | 具体怎么拍 |
| 骨架 | 本文第一节 | `07-video-scripts.md` 第二节（七节结构） |
| 文件命名 | `{客户}_出海社媒运营方案_{平台}_{日期}.md` | `{客户}_配套视频脚本方案_{日期}.md` |
| 条数 | 首批清单全部列出（含待素材） | **默认只展开能拍的 12 条**；待素材条目单列简表 |
| 关系 | — | 脚本编号必须能指认主方案第四章的首批清单编号 |

两份文档里的**参数必须一致**：主方案附录 E 参数卡写了什么，脚本字幕里就写什么。出现两个数，客户会当场质疑整份交付。

> 文件名里**禁用 `+` 号**，用下划线或「与」。`+` 在 URL 里会被解析成空格，客户端打不开文件。

## 二、裁剪规则

### 只有 1 个平台时
- 第三章改「三、落地：{平台}独有运营方式」，**取消 3.N 协同节**
- 2.1 改「内容结构与节奏」
- 附录 A/B/D 保留（单平台也要装修清单和标签库）
- 四、五、六、七**全部保留**（单平台更需要明确链路）

### 各章节保留条件

| 章节 | 保留条件 |
|---|---|
| 五、询盘转化链路 | **始终保留**（B2B 没有链路就只是发帖建议） |
| 六、90 天路线图 | 保留（客户与执行方对齐节奏需要） |
| 七、风险与合规 | 保留，控制在 1 页以内 |
| 附录 E 参数卡 | 客户产品有明显规格参数时保留（制造业必留） |

## 三、第五章：询盘转化链路

必须画成文字漏斗：

```
播放（曝光）→ 主页访问（门面）→ 互动（评论/私信）→ 询盘（DM/WhatsApp/表单）→ MQL
```

每一级给四项：**现状数字**（有截图数据时填，没有就写「需客户提供」）、**转化动作**、**责任人**、**KPI**。

**5.2 询盘必问要素** —— 第一句一次问完，5 项：
① 需要的规格/型号 ② 数量/MOQ ③ 目标市场或目的港 ④ 认证要求 ⑤ 交期期望

**5.3 响应 SOP**：
- 5 分钟内首响（B2B 黄金 5 分钟，超过 1 小时询盘质量断崖下降）
- 24 小时内给完整报价单
- 48 小时未回复跟进一次，之后转低频维护

## 四、第六章：90 天路线图

三阶段表格，不要写四阶段以上：

| 阶段 | 时间 | 核心动作 | 验收标准 |
|---|---|---|---|
| 第一阶段 建门面 | 第 1–4 周 | 装修 100% + 首批内容 + 养号 | 装修完成度 100%，中位数播放走出个位数 |
| 第二阶段 找结构 | 第 5–8 周 | 系列化 + 爆款结构复用 | 出现 3 条同结构高播放，评论区出现询盘 |
| 第三阶段 收询盘 | 第 9–13 周 | 链路固化 + 话术沉淀 | 可追踪询盘 ≥ {N} 条/月 |

验收标准必须可核对，不写「品牌认知提升」。

## 五、第七章：风险与合规（1 页以内）

### 🔴 先判断：客户产品是否适配 / 兼容他人品牌？

**配件、耗材、兼容件、OEM 代工件、第三方配件 —— 只要产品的价值建立在「适配某个他人品牌的产品」上，这一条必须写在第七章第一条，优先级高于其它所有风险。**

为什么：这类客户的账号生死不在内容质量，在商标。北美与西欧是商标执法最积极的市场，主要平台对商标投诉的处理是**直接限流或停号**，不给申诉空间。内容做得再好，一次投诉就归零。

必须写清四个部分：

| 部分 | 写什么 |
|---|---|
| **事实** | `{商标}` 权属 `{权利人}`；客户与该权利人无隶属关系（除客户另有说明） |
| **可以做的（指示性使用）** | 用 `Fits {品牌} {型号}` 句式说明适配对象；用自己拍摄的、自己持有的产品照片；照常标型号编号；加免责声明 `Third-party accessory. Not affiliated with {权利人}.` |
| **绝对不能做的** | 把商标放进品牌名 / 账号名 / handle / Logo；用权利人官方图、官方盒照、官方 Logo；任何暗示官方 / 授权 / 合作 / 联名的表述；用他人商标做付费广告定向 |
| **需客户立即确认** | ① 是否收到过商标投诉或平台警告 ② 是否有书面授权或默许 ③ 品牌名与 handle 是否含商标字样 |

**风险等级怎么判**：客户现有内容里若已出现「把商标当产品名用」（例：`{商标} Light-up Display`，而不是 `Fits {商标} {型号}`），判为 **中偏高**，并在 2.5 整改清单里列一条必改项。

> 边界拿不准时写「需客户法务确认」，**不要自己下结论**。这一条写错比写漏更危险。

### 其余风险（按客户实际挑 4–6 条）

- **数据隐私**（GDPR/CCPA）：不在内容中出现未授权的买家信息
- **广告与宣传合规**：不做绝对化用语、不虚假宣传认证
- **素材版权**：BGM 用平台官方免费商用音频库；不用他人官方宣传素材
- **产品认证合规**：含电子 / 电源 / 化学 / 儿童 / 食品接触相关的产品，目标市场通常有强制认证（北美 UL / ETL / FCC、欧盟 CE / REACH、加州 Prop 65），**客户没给就写「需客户确认」，不要假设已有**
- **平台政策风险**：AI 生成内容如适用需申报商业推广
- **账号安全**：2FA + 账号台账 + 环境固化
- **文化雷区**：目标市场宗教 / 节日 / 颜色禁忌
- **运输与售后**：易碎 / 大件 / 高客单品类的破损率与理赔政策，往往是差评与退款主因，主动讲清楚反而成为信任点

## 六、附录 A–F 标准

### A 装修清单
按平台分小节，逐项打勾，标注「第 1 周完成」。
列固定：`项 | 现状 | 目标 | 负责人 | 完成`

### B Bio 统一模板
五要素结构，可直接复制：

```
Who we are ｜ What we make（含关键规格） ｜ Certificates ｜ Sample & MOQ ｜ Contact
```

| 要素 | 内容 | 示例格式 |
|---|---|---|
| Who | 是谁 | `{Company}, since {year}` |
| Make | 做什么 + 关键规格 | `{Product}, {key spec}` |
| Cert | 认证 | `{ISO9001 / 第三方检测}` |
| Sample & MOQ | 样品与起订 | `Free sample, MOQ {N}` |
| Contact | 联系 | `WhatsApp +{phone} / {site}` |

**各平台字符上限不同，必须分别给一版**：Instagram 150 字符内 / X 160 字符内 / YouTube 1000 字符 / TikTok 80 字符内。

### C 询盘话术库
- C1 评论区钩子（每条视频固定置顶一条）
- C2 私信首轮回复（5 分钟内）
- C3 常见 4–6 问标准答案

### D 标签与关键词库

**标签三层法**：

```
品类词（1 个）+ 精准长尾（2 个）+ 行业/场景词（1 个）+ 品牌词（1 个）
```

三条铁律：
- **不要每条都用同一组标签**（会被判定机器人）
- 不要只用大流量标签（反而分不到流量）
- 品牌词固定 1 个，长期沉淀品牌词池

D2 要给的是**搜索关键词**（买家真正会搜的词），不是标签。英文版 + 目标语种版（如俄语/西语/阿语）分别给。

### E 产品参数卡模板
图卡与规格表通用字段：型号 / 材质 / 规格 / 公差 / 性能 / 认证 / MOQ / 交期。

### F 需客户确认事项
一次性列 8–12 项，让客户一次回完。**这一节的作用是减少反复拉扯，不是为了免责。**

## 七、语言与风格

### 句式
- 短句为主，一句一个意思
- **判断句多于描述句**（写「XX 是零起点」，不写「XX 的表现还有提升空间」）
- 每条建议后面跟「为什么」或「不做会怎样」

### 表格优先
凡三个以上并列项，一律用表格。段落只用于：核心矛盾、UVP、机制解释。

### 加粗规则
加粗只给三类：① 核心矛盾 ② 关键数字 ③ 必须纠正的认知。**不要整段加粗。**

### 判定符号
🟢 正确 / 🟡 有但不合格 / 🔴 零起点或致命问题 / ⭐ 优先级 / ✅ 已完成项

### 禁止的写法 → 改成什么

| 禁止 | 改成 |
|---|---|
| 提升品牌影响力 | 3 个月内让 `{具体搜索词}` 的前 10 条里出现 1 条自有内容 |
| 加强互动 | 每条视频发布后 30 分钟由账号自己置顶一条评论区钩子 |
| 优化内容质量 | 前 3 秒去掉 Logo 开场，改成 `{具体动作}` 特写 |
| 建议多发布 | 每周 4 条，周二/周四发 |
| 打造专业形象 | 头像换成 `{核心部位}` 剖面特写，手机端 40px 可辨识 |
