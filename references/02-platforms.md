# 逐平台独有打法手册

> 原则：**每个平台的「独有打法」必须是其他平台不适用的**，否则说明你写错了位置。
> 遇到某平台时只读那一节，不按顺序通读。

---

## 一、每个平台的写法模板（固定四段）

方案里每个平台章节都按这个结构写，不能变：

```
### 3.X {平台} —— 「{角色定位}」：{一句话打法}

**平台机制（当年必须知道的 K 条）**
- {机制1，带数字/官方依据}
- {机制2}
- {机制3}

**账号定位（一句话）**
> {一句话}

**{本客户的}独有打法（5–8 条）**
1. {动作} —— {怎么做}，{为什么}
2. ……

**禁忌（会直接压流量）**
- {禁忌} → {后果}
```

**三条硬要求**：
- 「平台机制」写的是平台**客观规则/算法机制**，不是你的建议
- 「独有打法」必须**换成别的平台就不成立**，否则是写错位置了
- 每条打法带可量化标准（时长 / 比例 / 数量 / 频次）

## 二、Facebook —— 「询盘成交位」

**平台机制**
- 信息流对 Reels 与「有互动的图文帖」给量，**静态产品图几乎零分发**
- 免费主页带外链帖被压到约 **2 条/月**；Meta 自报 98.9% 的美国帖子浏览不含任何外链，外链帖浏览占比 2022 年 9.8% → **1.3%**
- 监管动向（欧盟 DSA 裁定"成瘾式设计"违法）推动 feed 向有价值内容倾斜 → **干货帖比标题党安全**
- **B2B 成交常发生在 Messenger 私信，不在评论区**

**独有打法**
1. **主页当"第二个官网"装修**：四件套 = 封面图（产品+场景+认证三合一）/ Bio 五要素 / 服务栏（Get a Sample｜Spec Sheet & Price｜OEM｜Technical Support）/ 置顶 1 条身份内容
2. **Groups 渗透（Facebook 最大免费流量）**：找 5–8 个行业小组，**先评论答疑 2 周再发产品帖**；群组帖模板 = `[行业问题/常见误区] → [我们的做法与数据] → [欢迎交流/索取规格表]`，不带价格、不带链接
3. **Reels 复刻机制**：TikTok 验证过的结构直接剪 Facebook 版，但换首帧、换开场 3 秒
4. **Messenger 关键词自动回复**：catalog / price / moq / sample / datasheet / test report 六个关键词触发自动回复 + 人工跟进
5. **长图卡（Spec Card）**：Facebook 独有的高转发形式，单参数一图，6 图一组
6. **不把 Facebook 当导流管道**：指望"发帖带链接跳官网"是最大认知误区，改成「在站内完成信任 → 私信承接」

**禁忌**：外链帖连发（额度用光且本就无分发）｜群组直接发广告（被踢+主页关联风险）｜纯产品图平铺

## 三、Instagram —— 「视觉信任与品牌门面」

**平台机制**
- Reels 占 Instagram 总时长约 35%，算法持续向视频倾斜
- **轮播（Carousel）互动率高于单图**，适合参数对比/步骤教学
- 算法加权原创，聚合搬运号被清出推荐；"Your Algorithm" 扩展到主 feed → **账号主题越聚焦，分发越准**
- B2B 制造企业的 Instagram 真正价值：**有人来查你时，30 秒内建立专业印象**，不是流量

**独有打法**
1. **Reels : 轮播 : 单图 = 5 : 3 : 2**，轮播必做（A vs B 的 N 个区别、检测全流程、选型表）
2. **Highlights 建 4 个分类**：Products / Factory / Test Reports / Certificates —— 这是给访客的"证据目录"
3. **Stories 做工厂日常**：产线在跑、卡尺测量、装柜、展会，每天 1–3 条，成本极低信任感极强
4. **Bio 挂 Linktree**（正文不能放链接）：Spec Sheet / WhatsApp / Website 三入口
5. **Reels 复用 TikTok 素材但必须换首帧与配乐，且不能带水印**
6. 标签三层法，**每条换组合**

**禁忌**：带 TikTok 水印的搬运｜单图产品图刷屏｜所有帖子同一组标签

## 四、TikTok —— 「曝光引擎」

**平台机制**
- 算法用**完播率 + 分享率**决定是否进入下一级流量池，**分享率权重持续上升**
- 完播门槛约 **70%** —— 短视频不是"拍得短"，是"信息密度够高"
- **带水印的跨平台搬运会被降权**，必须原生上传
- 平台在主动清剿 AI 感与同质化内容 → **真人实拍 + 真实产线 + 真人出声**是安全线
- 美国区算法处于重训周期，**数据波动属正常**
- **评论区已升级为内容形式**，不再是附属品

**独有打法**
1. **TikTok SEO 四件套（与 Facebook 最本质的区别，每条都要做）**：① 口播里念出采购关键词 ② 全程烧英文字幕且含关键词 ③ caption 前 40 字符放关键词 ④ 三层标签组合
2. **系列化（从"杂货铺"变"专业号"的关键）**：固定栏目名 + 编号，例 `{产品英文名} Lab EP01/EP02`、`Proof EP01`、`How It's Made EP01`、`Ask {品牌} EP01`
3. **前 2 秒给动作或结论数字**，禁止 Logo 开场 / 厂房航拍开场
4. **一条只讲一个动作 + 一个数字**（示例格式：±0.1 mm / 80 MPa / 25 years / NOT {竞品材料}）
5. **评论区固定钩子**：`Comment "CATALOG" and we'll DM you the spec sheet + sample policy + price list.` 发布后 30 分钟由账号自己置顶
6. **视频长度 15–30 秒**，英文字幕全程烧字，数字必须带单位
7. **每周 1 场 15 分钟"车间巡场"直播**——免费的额外流量入口
8. **爆款复用**：高播放那条拆出它的结构（镜头类型/节奏/信息密度），做同结构续作，至少 3 条

**禁忌**：水印搬运｜所有帖子同一组标签｜只堆叠"库存感"画面（堆垛、装车）而不给参数｜新号突然高频发布

## 五、YouTube —— 「B2B 主战场：搜索 + 信任」

**平台机制**
- **Shorts 已是独立推荐系统**，核心指标是**划走率与完播百分比**，不是观看时长 → 每条 Short 当独立作品包装
- Shorts 支持自定义封面；平台收紧"不真实内容"变现政策 → 真人实拍 + 真实产线是被鼓励方向
- 长视频侧：B2B 买家在采购决策中会看视频，且工业品采购搜索词**搜索意图极强、竞争度远低于消费品**
- **描述区是少数能放完整链接且不限流的地方**

**独有打法**
1. **Shorts : 长视频 = 8 : 2**
2. **长视频只做四类**：① 产线全流程（3–5 分钟）② 怎么判断好坏（检测全流程，最易被收藏转发给同事）③ A vs B 选型科普（长尾搜索极强）④ 下游工艺与常见问题
3. **标题写成买家搜索句**，例：`{Product Name} ({Grade}): How Tolerance, {Key Property} and Tensile Strength Are Tested`
4. **描述区放三件套**：关键参数 + 认证说明 + WhatsApp 与官网
5. **长视频必须打 Chapters 时间轴**（0:00 原料 → 0:40 成型 → 1:30 公差测试）
6. **播放列表 3–4 个**，按内容栏目命名（Inside the Line / Test It Yourself / Why {材料} / Sourcing 101）
7. **长视频封面单独做**：剖面/卡尺/拉力机 + 大字结论（`±0.1 mm` / `80 MPa` / `NOT {竞品材料}`）
8. **零成本存量优化**：把已有视频的无关键词标题改成搜索句、补描述与标签

**禁忌**：把 Shorts 当长视频剪（要独立开场）｜标题写品牌口号不写搜索词｜所有内容塞一个大播放列表

## 六、LinkedIn —— 「决策层背书位」

**平台机制**
- **"反 AI 垃圾"开始有牙齿**：低质批量内容被限流
- 用户是决策角色（采购经理/技术总监/老板），**不吃娱乐内容，吃行业观点与数据**

**独有打法**
1. **内容形态以文本 + 单图为主**，不追短视频
2. **只发三类**：行业数据解读 / 工艺观点 / 项目与认证进展
3. **公司页 + 个人号双发**（老板/技术负责人个人号触达率远高于公司页）
4. **每周 2–3 条**，不做日更
5. 工业型材、自动化设备、精密加工类买家在 LinkedIn 与 Google 搜索更活跃 → 社媒只做**辅助佐证**

**禁忌**：把 TikTok/Instagram 内容直接搬过来｜发娱乐化内容｜日更刷屏

---

## 七、X (Twitter) —— 「行业背书位，不作流量考核」

**平台机制**
- 战略重心转向支付/金融，**媒体分发属性弱化**
- 视频能力在增加，但 **B2B 品牌不应抱有流量预期**

**独有打法**
1. **每周 1 条**：认证/标准动态、材料观点、发货与展会
2. **作用是给 Google 搜索与客户背景调查留"活着"的痕迹**
3. **不单独拍摄**，复用图卡或装柜照片
4. **行业观察轻互动**：回复行业账号与媒体的讨论——X 唯一低成本的 B2B 价值

**禁忌**：把它当流量平台做考核｜日更｜发纯产品广告

## 八、VK（VKontakte）—— 「俄语区收割」

**平台机制**
- 俄语区（俄罗斯/哈萨克斯坦/白俄罗斯/乌兹别克斯坦）**第一社媒**，Facebook 在俄受限后 VK 成主战场
- 用户在 VK 找供应商、看 **OE 号/型号**、进行业社群
- 平台有社群（社区）机制，可建企业社区 + 商品目录

**独有打法**
1. **核心原则：VK 不是"英文内容的俄语版"，是"为俄语买家重做一遍"** —— 必须母语级俄语，不能有机翻痕迹
2. **VK 社区五件套（第 1 周建好）**：社区封面 / 简介（含 OE 号与车型适配）/ 商品目录（带价格区间或"询价"）/ 联系方式 / 置顶帖（产品全系总览）
3. **内容对着俄语区买家最痛的两件事打**：进口替代（本地买不到货）+ 交期与付款方式
4. **帖子母版**：单型号长图文（型号 + 适配车型 + 参数 + 起订 + 交期 + 联系方式）
5. **必须给俄语标签与俄语搜索词**，不能只用英文
6. 周节奏：每周 3–5 条帖子 + 社群互动

**禁忌**：机翻俄语｜只发英文｜不给 OE 号/型号（俄语区买家靠型号找货）

## 九、Threads —— 「轻量补充位」

**平台机制**
- 与 Instagram 账号打通，文本为主，分发依赖 Instagram 关系链
- B2B 采购决策场景弱，适合做**行业观点与轻互动**，不适合承载询盘

**独有打法**
1. **每周 1–2 条短文本观点**（≤ 200 字），复用 Instagram/TikTok 内容的核心结论
2. 作用是**品牌存在感**，不设流量指标
3. 可做「行业提问」引发同行讨论

**禁忌**：作为主攻平台｜发长文｜发硬广

## 十、多平台协同：「一条素材 × N 平台剪法」

方案里必须给一张矩阵表，然后给下面 **5 条剪法规则**（固定，不因人而异）：

| 素材 | 比例 | 开场 3 秒 | 首帧封面 | 标题逻辑 |
|---|---|---|---|---|
| 同一条原片 | 16:9 / 9:16 / 1:1 | 每平台剪不同开场 | 各平台单独做 | 见下表 |

| 平台 | 标题逻辑 |
|---|---|
| YouTube | 搜索句（买家会怎么搜） |
| TikTok | 短钩子（结论数字或冲突） |
| Instagram | 利益点 |
| Facebook | 问题句 |
| LinkedIn | 观点 |

**第 5 条规则：原声保留。** 现场声是专业感来源，别被 BGM 盖掉。

**加一条铁律：带水印的跨平台搬运会被降权，必须原生上传。**

## 十一、平台角色速查（选平台时用）

| 平台 | 一句话角色 | 承担指标 | 是否承载询盘 |
|---|---|---|---|
| TikTok | 曝光引擎 | 播放中位数、完播率 | 间接种草，评论钩子 |
| Facebook | 询盘成交位 | 询盘数、群组互动 | ✅ 主战场（Messenger） |
| YouTube | B2B 搜索与信任 | 搜索曝光、观看时长 | ✅ 描述区链接 + 私信 |
| Instagram | 视觉信任与门面 | 主页访问、收藏 | 🟡 次要（DM） |
| LinkedIn | 决策层背书 | 关注者质量 | 🟡 次要 |
| X | 行业背书 | 存在感 | ❌ |
| VK | 俄语区收割 | 询盘数 | ✅ 主战场（俄语区） |
| Threads | 轻量补充 | 存在感 | ❌ |

## 十二、平台组合建议（按客户类型）

| 客户类型 | 推荐组合 | 理由 |
|---|---|---|
| B2B 制造业（通用） | TikTok + Facebook | 曝光 + 询盘闭环，投入产出比最高 |
| 高选型决策品类（材料/零部件） | YouTube + Facebook | 搜索意图强，买家会反复回看 |
| 俄语区/中亚出口 | VK + TikTok | VK 是俄语区第一入口 |
| 视觉类产品（家居/纺织/包装） | Instagram + Facebook | 视觉驱动决策 |
| 自动化/设备/工业集成 | LinkedIn + YouTube | 决策层在 LinkedIn，技术验证在 YouTube |
| 0→1 全新建号 | YouTube + Facebook 占 70% | B2B 搜索与询盘优先，TikTok/Instagram 承担曝光与门面 |
