# 骨架示例：B2B 出海制造（通用型）

> 这是唯一一个随包提供的完整骨架，用于示范「结构应该长什么样」和「优质段落是什么水准」。
> 不含任何真实客户信息，行业设定为虚构。使用时按客户实际情况替换，骨架本身不要改。

---

## 一、这个骨架适用的客户

**特征**：B2B 制造或贸易，有一到多条产品线，买家是品牌方 / 经销商 / 批发商 / 工程商中的两到三类，采购决策看参数与认证。

**典型行业**：工业零部件、材料、机械设备、包装、纺织、家居用品、五金、汽配。

**不适用**：纯消费品零售、纯服务、没有实物的 SaaS。

---

## 二、骨架要点（照这个思路搭）

1. **买家分层写清四类诉求差异**
   品牌方看交期与一致性，经销商看价差与独家，批发商看库存周转，工程商看认证与售后。四类诉求不同 → 内容必须分层，不能一套打所有人。

2. **平台组合先判品类属性**
   - 参数驱动（材料/零部件/设备）→ **YouTube + Facebook**
   - 视觉驱动（家居/纺织/包装）→ **Instagram + Facebook**，Instagram 权重上升
   - 俄语区出口 → 加 **VK**

3. **内容三支柱**（三类缺一不可）
   产品细节特写（材质/做工/规格）→ 使用场景（真实产线/客户现场/下游应用）→ 工艺与品控（产线/检验/包装）

4. **「一个拍摄日拍够一个月」是硬约束**
   产能受限的客户，先把拍摄日排明白，再谈内容数量。做不到的内容数量等于画饼。

---

## 三、内容板块基准比例

**参数驱动型（材料/零部件/设备）**

| 板块 | 占比 |
|---|---|
| 证据型（实测/检测/对比实验） | 35% |
| 工艺与品控（产线/过程控制） | 25% |
| 选型与问题解答 | 20% |
| 应用场景与下游工艺 | 12% |
| 客户案例与认证 | 8% |

**视觉驱动型（家居/纺织/包装）**

| 板块 | 占比 |
|---|---|
| 产品细节与色卡 | 30% |
| 使用场景 | 25% |
| 工艺与品控 | 20% |
| 选型/材质科普 | 15% |
| 客户案例与认证 | 10% |

> 两套比例的共同底线：**证据型 + 工艺品控合计不低于 45%**。低于这个数，内容就变成产品图流水账，B2B 买家不会为它询盘。

---

## 四、优质实例：内容板块怎么落到具体选题

不是写"产品展示 30%"，而是每一条都能指到具体选题。

**参数驱动示例（虚构：某工业密封件制造商）**

| 板块 | 具体选题 |
|---|---|
| 证据型 | 同批次 10 件公差实测 / 高低温循环后弹性恢复对比 / 与竞品材料的压缩永久变形对比 |
| 工艺与品控 | 从原料到成型的完整产线 / 每 500 件抽检流程 / 模具更换与首件确认 |
| 选型 | 按介质选材的对照表 / 温度区间选型 / 常见渗漏的 5 个原因 |
| 应用场景 | 装到下游设备上的实拍 / 客户现场更换过程 |
| 案例与认证 | 第三方检测报告逐页解读 / 某行业认证的取得过程 |

## 五、优质实例：前 3 秒钩子（B2B 专用 5 种）

B2B 的钩子不是"震惊体"，是**让懂行的人立刻知道你有货**。

| 类型 | 示例 |
|---|---|
| 数字型 | `±0.05 mm across 10,000 pieces. Every batch.` |
| 对比型 | `Same spec. One passed 500 hours, one failed at 80.` |
| 结果先行型 | `This is why your seals leak in winter.` |
| 反常识型 | `Thicker is not stronger. Here's the test.` |
| 现场型 | `Raw material in, finished part out. One line, one take.` |

**共同点**：前 3 秒必须出现一个具体名词或具体数字，不能是品牌名、Logo、厂房航拍。

## 六、优质实例：核心矛盾的写法

核心矛盾是整份方案的支点，必须是一句话，且后面每一章都能呼应它。

**写法**：`{客户的真实优势}` × `{客户当前的错误做法}` → `{导致的结果}`

**示例（虚构）**：
> 这家厂的检测能力足以支撑行业级的技术信任，但所有内容都在拍成品货架，买家看不到任何检测过程——等于把最贵的资产藏起来了。

**坏的写法**：
> 品牌影响力不足，内容质量有待提升，需要加强专业形象建设。
> （空话三连，客户看完不知道该干什么）

## 七、跨所有行业通用的五条基线

这五条不分行业，每份方案都要满足。

### 1. 体检解读的三句话模板

> **播放头部集中度**：最高一条占 X% → {偶然命中推荐池 / 已有可复制结构}
> **中位数**：{个位数 = 从未进入推荐池 / 三位数 = 已进池但不稳定}
> **粉丝转化**：X 播放换来 Y 粉丝 → 流量与关注之间是断的

### 2. 「已经做对的部分」必备五个角度

素材真实性 / 产能可见度 / 产品线宽度 / 执行链路是否已通 / 是否出现过爆款

> 至少要覆盖 3 个角度。这一节的作用是让客户愿意继续听你说下去——只讲问题的方案，客户会用"你不了解我们"顶回来。

### 3. 首月内容条数基准

- 单平台 **12–16 条**
- 双平台合计 **24–28 条**
- 三平台以上不超过 **12 条主线**（多平台会摊薄）

**平台越多，单平台内容密度越低，宁可少平台做深。**

### 4. 拍摄日基准

| 类型 | 需要拍摄日 |
|---|---|
| 纯产品类 | 1 个拍摄日（4 小时）够 12–16 条 |
| 需产线 + 实测类 | 2 个拍摄日（4h + 3h） |
| 需场景/模特类 | 2–3 个拍摄日 |

输出时必须给「拍摄日清单」：场地 / 顺序 / 每条覆盖哪几个脚本 / 时长。

### 5. 询盘链路必画

B2B 方案缺了这一章，就只是"发帖建议"，不是运营方案。

```
播放 → 主页访问 → 互动（评论/私信）→ 询盘（私信/WhatsApp/表单）→ MQL
```

每一级都要写：**当前估算值（或标"需客户提供"）、卡在哪、这一级由哪个动作推动**。
