# 出海社媒运营方案 Playbook

> 把 B2B 制造企业的「我们也要做出海社媒」变成两份**明天就能开工**的文档：
> **一份运营方案**（做什么）+ **一份配套视频脚本**（怎么拍）。

一个给 Claude Code / Codex / OpenClaw 等 AI 编程助手用的 **skill**（技能包）。
不是提示词模板，是一套带硬红线、按需加载的知识体系 + 自检清单。

---

## 它解决什么问题

让 AI 写一份出海社媒方案，得到的通常是这样：

> 加强品牌建设，提升内容质量，建议多平台分发，配合广告投放扩大曝光，持续优化用户互动……

这类输出没有错，但没有人能照着它干活。

这个 skill 强制要求的是这样：

> 前 3 秒去掉 Logo 开场，改成卡尺夹住断面的特写，读数屏占画面 1/3。
> 你现有最高播放那条占总量 91.9%，其余平均 224 —— 说明是偶然命中推荐池，不是可复制结构。
> 首期 70% 产能给 YouTube + Facebook，TikTok 只做曝光，因为你的买家是采购经理不是消费者。

差别不在于"AI 更强了"，而在于**往对话里塞了一套判断标准**。

## 用法

直接用自然语言说需求，助手会自己加载这个 skill：

```
帮我给这家做铝型材的公司出一份出海社媒方案
我们做汽车配件，主攻中东和俄语区，TikTok 和 Facebook 怎么做
账号做了半年没流量，帮我看看问题出在哪
```

提供的材料越具体，产出越可执行：

| 给什么 | 效果 |
|---|---|
| 公司名 + 行业 + 产品线 + 目标市场 | 能出完整方案（账号部分会标「需客户确认」） |
| 再加账号截图 | 诊断章能落到实测数据 |
| 再加现有内容表现 / 询盘记录 | 诊断能指出结构性问题，不只是表面问题 |

## 三条它守得比较死的原则

**1. 数据必须有出处。**
每个数据点只能是三种状态之一：客户提供的、公开可查的、明确标为「推断」并给出依据。找不到出处就写「需客户确认」。B2B 客户里一定有懂行的采购，一个编造的数字会让整份方案的信任度归零。

**2. 不写不能执行的建议。**
「提升品牌影响力」这类句式被列为禁止项。每条建议都要能被被执行人在当天动手。

**3. 不做效果承诺。**
不写「保证播放量」「30 天涨粉一万」。目标只能写成「区间 + 前提条件」。定了不可控的数字，执行团队会被逼着作假，最后连真实数据都拿不到。

## 边界

**本期只覆盖社媒。** 广告投放方案与落地页方案不在范围内 —— 这两块各有独立的机制、计价与合规逻辑，混进社媒方法论里会两头都做不深。

**不替代行业认知。** 这个 skill 提供的是结构与判断标准，具体的技术卖点、参数可信度、买家真实关心什么，仍然取决于使用者对自己行业的理解。它会追问，但不会替你回答。

**不含任何客户信息。** 方法论源自 50+ 家 B2B 出海社媒项目的结构提炼，已完整脱敏：没有客户名称、账号、真实效果数据或商业课程原文。

---

## 适合谁

- 做出海 B2B 的市场 / 运营 / 销售负责人
- 服务制造业客户的代理商、咨询顾问
- 需要给客户出方案但不想每次都从零搭结构的团队

不适合：纯消费品零售、纯服务型业务、B2B 但完全不走社媒获客的场景。
